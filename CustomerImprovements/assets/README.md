# Customer Improvements assets

Files the mod loads at runtime, packed into its zip next to the DLL.

Shopping cart:

- `ShoppingCart.obj`: the cart model, shipped as it is
- `BaseColor.png`: its texture, shipped as `ShoppingCart.png`
- `Normals.png`, `Metalness.png`, `Roughness.png`: the model's other texture maps, not used (yet)

The shopping cart model is by mechano-file, under the MIT License: see `LICENSE-ShoppingCart.txt`, which ships in
the mod's zip with the model.
